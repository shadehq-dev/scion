Haunt 0.3.2: no more white window at start. It is still in development: expect rough edges, and expect things to change between versions before 1.0. This is a pre-release; it becomes the latest release once it has had some use.

## Better

- **Start-up.** Haunt opens on its own background colour (your theme.json's page colour, or light or dark as Appearance, theme.json or the system says) with its ghost floating in the middle until it is ready, instead of a blank white window.

## Install

| System | File |
|---|---|
| Windows | `Haunt_0.3.2_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon | `Haunt_0.3.2_aarch64.dmg` |
| macOS, Intel | `Haunt_0.3.2_x64.dmg` |
| Linux | `.deb` (Debian, Ubuntu), `.rpm` (Fedora), or the `.AppImage` |
| Arch, CachyOS | `haunt-bin-0.3.2-1-x86_64.pkg.tar.zst`: download it, then `sudo pacman -U` it |

Haunt needs git 2.24 or later. For TypeScript and JavaScript it uses Node 22.18 or later, or else Bun or Deno; without any of them it still reads the other languages.

## Known limits

The same as 0.3.0: the installers are not signed yet, the Linux additions have seen little use on a real desktop, and `haunt-bin` is not on the AUR yet. See the [0.3.0 notes](https://github.com/razerghost/haunt/releases/tag/v0.3.0).

Found a problem? Please [open an issue](https://github.com/razerghost/haunt/issues).
